# Book of Proofs — My Progress

The purpose of this repository is to keep track of my progress as I work through **Book of Proofs** by *Richard Hammack*.

I’m doing this purely as a hobby. I simply love mathematics, and I thought, why not spend some time learning it properly? This repository is a small record of that journey.

The repo contains the following:

1. progress.md — My daily log, where I record what I studied, what I worked on, and any thoughts or observations from that day.
2. notes/ — A collection of notes organized by chapter. These may contain interesting ideas, observations, proofs, questions, or anything else I come across that I find worth writing down.

This is not meant to be a polished set of notes or a formal course log. It’s simply a record of me learning, exploring, and hopefully getting a little better at mathematics along the way.

Wishing myself the best of luck! ♡
